民医連会計 推進士試験対策 PWA（初期版）

収録：第1～3回通信講座の問題に基づく21小問。
※公式模範解答との照合は未実施です。学習用の改題を含みます。

【公開・インストール】
PWAとしてスマートフォンにインストールするには、ファイル一式をHTTPS対応の静的Webホスティング（GitHub Pages等）に公開してください。
公開したURLをAndroid ChromeやiPhone Safariで開き、メニューから「ホーム画面に追加」します。
最初のオンラインアクセス後は、キャッシュ済みの問題をオフラインで利用できます。

【パソコンで動作確認】
Pythonが入っている場合、このフォルダで次を実行：
python -m http.server 8000
ブラウザで http://localhost:8000 を開いてください。
index.htmlを直接ダブルクリックすると問題データの読み込みに失敗する場合があります。

【履歴】
ブラウザのlocalStorageに端末ごとに保存。端末間の自動同期なし。
「履歴をバックアップ」でJSON書き出し、別端末で「履歴を読み込む」も可能です。

【注意】
今回の納品物はホスティング前のアプリ一式です。公開URLはまだありません。
